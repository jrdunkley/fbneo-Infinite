LATENCY AND MOTION

The corrected seven-pass chain processes the current game frame without an
intentional extra-frame queue. A production GPU readback test verifies that a
new bright input appears in that same frame on both alternating buffers, with
the first bright frame exactly matching the steady bright image. This test
does not measure physical input-to-display latency or the presentation queue.

The original afterglow retains up to 4% (Studio), 8% (Consumer) or 5% (1084S)
of the previous frame's linear brightness. This can leave visible fading trails.
It does not hold back the current bright image; dark transitions fade by design.

Static prototype rendering on an NVIDIA GeForce RTX 4070 measured approximately
0.51-0.54 ms/frame for the three looks at 1440x1080; Studio measured 0.41 ms at
960x720 and 1.11 ms at 2880x2160. These figures include a final GPU readback and
are rendering-cost observations, not measured added input/display latency.
Slower GPUs and missed presentation deadlines can cause additional delay.

Matched physical input-to-picture A/B testing and representative GPU/frame-
pacing measurements remain required before release. An additional whole frame
is a release blocker. No zero-latency claim is made from these software tests.
